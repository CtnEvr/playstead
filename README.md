# PlayStead

PlayStead is a collection of 12 offline games for iPhone and iPad.

No ads.  
No subscriptions.  
No account required.  
No internet connection required.

## Games Included

- Number Merge
- Block Puzzle
- Sudoku
- Pocket Glider
- Snake
- Word Grid
- Four in a Row
- Dots & Boxes
- Reaction Duel
- Suit Shift
- Minefold
- Trimrise

## About

PlayStead is designed as a simple, self-contained game collection that can be played anywhere without an internet connection.

Some games are designed for solo play, while others support local two-player play on the same device.
